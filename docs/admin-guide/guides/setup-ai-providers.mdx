AI providers are configured by the platform admin to centrally manage credentials and access, making AI qadams (OpenAI, Anthropic, Gemini, etc.) and their features available to everyone in all projects.

## Supported Providers

- **OpenAI**
- **Anthropic**
- **Gemini**
- **Vercel AI Gateway**
- **Cloudflare AI Gateway**

## How to Setup

Go to **Admin Console** → **AI** page. Add your provider's base URL and API key. These settings apply to all projects.

![Manage AI Providers](/resources/screenshots/configure-ai-provider.png)

## Reasoning in chat

Chat can ask the model to think before it answers and show that reasoning in a collapsible block. It is off by default, because every turn then costs more tokens and takes longer.

To turn it on, edit an **Anthropic**, **Amazon Bedrock**, **OpenRouter** or **Google** provider and switch on **Reasoning in chat**. The setting applies only to the provider enabled for chat. Flow steps and AI qadams ignore it. On Bedrock, the switch affects only Claude models; other Bedrock models answer as they would with it off.

**Reasoning budget** is the most tokens the model may spend thinking on each step, from 1,024 to 24,000:

- **Claude 3.7 through 4.5**, on Anthropic or Bedrock, and **OpenRouter** models use the budget.
- **Claude 4.6 and later** decide how much to think on their own, and ignore the budget.
- **Claude models before 3.7** cannot reason, so chat asks them for nothing and they answer as they would with the switch off.
- **Gemini** thinks by default and ignores the budget. The setting only makes Gemini return its reasoning.

On Claude 3.7 through 4.5, directly or through Bedrock, a reply that follows a reply in which the assistant used a tool may come back without reasoning. Anthropic turns thinking off for that request instead of failing it, so the reply itself is unaffected. This has not been tested against a live provider.

<Note>
For OpenAI, Azure, Mistral, custom and Cloudflare Gateway providers the switch does not appear. For a custom OpenAI-compatible server, send the server's own thinking parameter in **Extra request parameters** instead, for example `{ "chat_template_kwargs": { "enable_thinking": true } }` on vLLM.
</Note>

## Cost Control & Logging

Use an AI gateway like **Vercel AI Gateway** or **Cloudflare AI Gateway** to:

- Set rate limits and budgets
- Log and monitor all AI requests
- Track usage across projects

Just set the gateway URL as your provider's base URL in the Admin Console.
